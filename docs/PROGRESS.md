## 2. 下一任务说明

### TQ-001：定义 CardSemanticProfile Schema

**状态：NEXT**

目标：

- 把 `CARD_DATA_STANDARD.md` 中的建议结构收敛为正式数据契约。
- 定义必填字段、枚举、数值范围、交叉引用和版本字段。
- 建立最小校验器和自动测试。

开始前必须读取：

- `AGENTS.md`
- `docs/DECISIONS.md`
- `docs/ENGINE_ARCHITECTURE.md`
- `docs/CARD_DATA_STANDARD.md`
- `docs/ROADMAP.md` 中 TQ-001 至 TQ-004
- 当前 `data.js` 中 78 张牌的数据结构
- 当前测试文件

建议产物：

- `engine/card_schema.js`
- `engine/vocabularies.js` 的最小枚举骨架，若 Schema 需要
- `tests/card_schema_test.js`
- 必要时更新现有测试入口

本任务不应：

- 批量改写 78 张牌
- 改变四种牌阵
- 扩展预设问题
- 实现多牌综合
- 引入第三方大型校验框架

验收标准：

1. 一个完整样本可以通过校验。
2. 缺少必填字段时失败。
3. 非法枚举和关系标签时失败。
4. 数值越界时失败。
5. 正逆位权重非法时失败。
6. 错误引用或重复 ID 时失败。
7. 测试可在项目现有环境运行。
8. 本文件更新为下一任务 `TQ-002`。

## 5. 当前代码基线

截至 2026-07-30 的代码审查结论：

- 项目为离线浏览器应用，Python 只提供本地服务和生命周期控制。
- 当前包含 78 张牌、42 个固定问题和 4 种固定牌阵。
- 当前抽牌使用安全随机源优先的洗牌逻辑，牌面在动画前已确定。
- 当前单牌资料主要由关键词、正逆位说明和固定建议组成，适合展示，不足以支持目标规则引擎。
- 当前具体问题没有独立推理配置，综合逻辑主要依赖六大问题分类。
- 当前综合结论存在依赖正逆位数量、主导元素和固定模板的情况。
- 当前全部大阿卡纳归为“灵”，会造成元素统计偏斜。
- 当前历史记录未保存完整证据链、规则版本或可复现随机种子。
- 当前测试主要检查卡牌数量、字段存在和牌阵位置，尚未覆盖语义质量与关系推理。

这些问题应按路线图分阶段修复，不要在 TQ-001 中顺手全部改掉。
