# Phase 8：评测、恢复、无障碍与UI

## 阶段范围

本阶段连续完成 `EV-001`、`EV-002`、`EV-003A/B/C`、`EV-004`、`EV-000B`、`ERR-001A-D`、`AX-001`、`UI-001`、`UI-002` 与 `AX-002`。

## 评测边界

- 开发评测可以提交仓库。
- 最终盲测正文不进入仓库；仓库只保存数量、政策、SHA-256 和聚合结果。
- 日志不得输出盲测正文、问题正文、完整解读、根种子或历史正文。
- 单牌、多牌和问题贴合三项核心平均分及最低分均不得低于 9.0。
- 修改资料、问题、牌位、引擎、权重、模板或UI输入适配器会使盲测失效。

## 恢复边界

- 错误使用稳定错误码、严重级别、白名单上下文、用户消息和恢复动作。
- 资料或引擎失败保留已抽牌，不重抽。
- 存储和迁移失败不删除旧记录；导入失败不改变现有记录。
- 诊断最多保存有限条目，且不含用户问题、解读正文、历史正文或随机根种子。

## UI与无障碍边界

- UI通过 `reading-engine.js` 消费 Observation、Relation、Claim 和渲染结果，不重新实现规则。
- 兼容历史只保存结构化摘要，完整证据仍存于 IndexedDB。
- 标签页支持方向键、Home 和 End；牌桌支持方向键导航。
- 动态牌面包含序号、牌位、牌名、正逆位和可读状态。
- 对话框打开后焦点进入，关闭后返回触发元素。
- 错误恢复面板使用 `alert/status`，不会在无错误时抢夺焦点。
