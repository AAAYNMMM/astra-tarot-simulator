# 星纱塔罗 2.0.0

2.0.0 是纯规则、离线、可复现和可审计版本。

## 主要变化

- 78张牌结构化资料、90个固定问题与四种固定牌阵。
- Observation、Relation、Claim 和双层文本校验完整接入真实界面。
- 抽牌、正逆位和渲染使用相互独立的版本化随机流。
- 完整历史进入 IndexedDB，并保存版本、证据与 artifact 指纹。
- 552例开发评测和48例受控盲测均通过发布门禁。
- 错误恢复、诊断导出、键盘、焦点和屏幕阅读器流程完成。
- PWA使用临时缓存、受控切换、多标签协调和上一稳定版本回滚。
- 四套牌组按需管理，不再让首次安装替人类缓存一整座美术馆。

## 不变边界

- 不调用AI大模型或在线生成服务。
- 不接受自由文本问题。
- 不新增或改变四种牌阵。
- 不根据问题、期望答案或牌义调整抽牌。
- 塔罗内容用于自我觉察、叙事探索和娱乐，不替代专业意见。
