# 项目开发路线图

## 1. 文档职责

本路线图只提供阶段导航、任务目录和阶段出口。

- 锁定决策：`DECISIONS.md`
- 唯一任务图、依赖、状态和发布顺序：`EXECUTION_CONTRACTS.md`
- 当前活动任务和唯一下一任务：`PROGRESS.md`
- 领域要求：模块化、数据、工程、最终质量、引擎和单牌标准文档

若本文件与执行契约冲突，以 `EXECUTION_CONTRACTS.md` 为准。

6. `MOD-004B`：服务器访问边界和生命周期保护。
7. `MOD-005`：人工知识源和旧版解读适配。
8. `MOD-006A`：删除兼容桥、旧全局和旧大型文件。
9. `MOD-006B`：正式生成目录、注册表、清单和artifact manifest。
10. `MOD-006C`：PWA资源类型、等级和离线状态。

- 真实应用完全通过原生ES Modules运行。

- 生成文件没有双重真相。
- 当前commit取得CWapi full RESULT。

## 15. 任务选择原则

1. 优先恢复 `PROGRESS.md` 中的 `IN_PROGRESS` 或 `BLOCKED` 叶子任务。
2. 没有活动任务时执行唯一 `NEXT`。
3. 父任务不能直接执行或成为 `NEXT`。
4. 任务进入 `NEXT` 前满足执行契约的就绪定义。
5. 非纯文档任务绑定完整commit和CWapi RESULT。
6. 不跳过Schema、词典、评测协议、黄金样本、完整QP/PO契约和消费验证。
7. 连续审查在两轮无新重大问题后停止，开始执行当前任务。
