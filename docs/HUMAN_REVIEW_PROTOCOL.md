# Phase 8 独立人工评审流程

## 评审目的

人工评审只判断结构化规则结果是否正确、贴合、可解释和安全。文笔流畅不能抵消牌义错误、问题偏离、证据缺失或越权断言。

## 盲化

- 评审包只显示 `candidate-A`，不显示旧版、新版或实现来源。
- 每位评审独立评分，不查看其他评审结果。
- 数据集使用固定 SHA-256；修改评审包后旧评分失效。

## 七个分项

每项 0–10 分：单牌语义准确、问题贴合、牌位职责、多牌整合、证据与条件、安全边界、清晰度。任一前六项低于 8 分时，不得因清晰度高而通过。

## 分歧与复审

任一分项评审差异超过 1.5 分进入复审。复审追加理由、最终分数、协议版本、日期和数据集哈希，不覆盖原始评分。

## 通过规则

三项核心总平均均不低于 9.0；禁止断言为零；证据引用、条件和冲突说明不得缺失；最终盲测由 CWapi 受控数据集执行，仓库不保存案例正文。
