# 星纱塔罗 2.1.0

2.1.0是稳定性、响应速度和精简解读版本，上一完整发布为2.0.0。

## 用户可见变化

- 翻牌后先显示一句结论、2至4条关键依据、成立前提、停止信号和下一步；逐牌依据按需展开。
- 洗牌缩短，发牌和全部翻开改为有界并行动画；减少动画模式不再保留非必要等待。
- 解读失败保留原牌，可使用稳定错误码重试，不会静默重抽。
- 历史记录显示中文结论和摘要，内部结论码与原始分数收进“技术详情”。

## 规则与兼容

- 运行时仍为纯离线确定性规则，不调用AI或外部服务。
- 固定90题、四种牌阵、牌位和业务ID不变。
- 解读结果Schema提升为4.0.0；ReadingRecord 2.0增加可选精简解读快照，旧记录继续按兼容矩阵读取。
- Worker只预热核心模块，当前问题和抽中的牌义按需加载。

## 修复与验证

- 正常出现“可能”“可能性”或“力量”等普通词不再造成解读失败。
- 最终摘要必须引用结果位，并在结果风险与主结论冲突时收紧判断。
- 四个manifest PNG图标可由本地服务器真实返回。
- 发布门禁包含56160例真实数据矩阵、四牌阵浏览器流程、PWA资源和完整回归。

最终发布仍需由CWapi对完整commit执行full验证和受控独立盲评；仓库不保存盲测正文。
